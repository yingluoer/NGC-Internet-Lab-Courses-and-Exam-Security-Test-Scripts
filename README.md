## 说明

两个构建，代码相同，区别只在账号绑定：

| 文件 | 绑定 | 说明 |
|---|---|---|
| `NgcV2.4.15.exe` | 有 | 首次登录锁定本机，只能跑该账号 |
| `NgcY2.4.15.exe` | 无 | 可多账号切换、批量 |

双击启动本地服务并打开浏览器，界面在 `http://127.0.0.1:8769/`。端口被占用会自动顺延。

## 功能

| 功能 | 说明 |
|---|---|
| 登录 | 图形验证码本地 OCR 识别，失败自动重试 |

## 用法

双击 exe，浏览器自动打开控制台。

1. 输入学号，点 `CONNECT`
2. 左侧选择已登录终端
3. 点「执行学习」，等进度跑满
4. 需要模考就点「全真模考」，练到稳定 90 分以上
5. 需要证书点「下载证书」

命令行模式：

```bash
python nk_auto.py login                  # 登录，会话存 session.json，约 4 小时有效
python nk_auto.py status                 # 查看进度
python nk_auto.py learn --dry-run        # 预演，不写任何数据
python nk_auto.py learn                  # 正式学习
python nk_auto.py learn --only 水电安全   # 只学一门
```

| 参数 | 作用 |
|---|---|
| `--user` | 学号，密码默认同学号 |
| `--only` | 只处理课程名含该关键字的课程 |
| `--dry-run` | 只打印计划，不调用写接口 |
| `--relogin` | 强制重新登录 |
| `--headed` | 登录时显示浏览器窗口 |

## 题库

```bash
python question_bank.py export                        # 导出，20 分类 / 4288 题
python question_bank.py stat                          # 统计
python question_bank.py mock                          # 随机 10 题，终端作答，自动判分
python question_bank.py mock --num 20 --types 水电安全,消防安全
python question_bank.py mock --seed 42                # 固定随机种子
```

导出为 `question_bank.json` 与 `question_bank.csv`。交卷后列出错题的题干、选项、你的答案与正确答案。
